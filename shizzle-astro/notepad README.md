# Shizzle — Personal Website

Official personal website for **Shizzle**, Czech rapper and performer.

The website presents Shizzle's music, upcoming concerts, media, biography and booking/contact information.

## Tech Stack

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript
- Astro Content Collections
- Behold — Instagram feed
- Spotify Embed
- YouTube
- Vercel

## Features

- Responsive, mobile-first design
- Concerts carousel
- Discography
- YouTube clips
- Instagram feed
- Biography
- Booking and contact section
- Downloadable press materials
- SEO metadata and sitemap
- Optimized WebP images
- Accessible semantic HTML
